# Contributing to OneTask

OneTask is a personal project maintained by me for my own use. Thank you for your interest.

## Pull requests

**Pull requests are not accepted.** The project moves at the pace of my own needs and review bandwidth, and I can't commit to the ongoing obligation of merging, reviewing, or supporting external contributions.

If OneTask doesn't do what you need, you are warmly encouraged to **fork it** and adapt it freely under the terms of the AGPL-3.0 license.

## Issues

Issues are welcome. I may not respond or act on them, but they're read, and they're useful as a record for other people running forks.

If you file an issue, please include:
- What you expected to happen
- What actually happened
- Your Python version, TaskWarrior version, and OS
- Any relevant error output

## Security issues

Please do **not** open a public issue for security vulnerabilities. See [`SECURITY.md`](SECURITY.md) for how to report them privately.

## Forking

If you fork OneTask, the AGPL-3.0 license requires that you make your modified source available to anyone who uses your version as a network service. See the [`LICENSE`](LICENSE) file for the full terms.
